The other files are used by Halo's built-in updater; you don't need to download them.

**Mac:** open the disk image, drag Halo onto Applications, then open Halo from Applications. Halo isn't notarised by Apple, so the first time macOS says it couldn't verify Halo: click **Done**, open **System Settings › Privacy & Security**, click **Open Anyway** next to Halo and confirm. You only do this once.

**Windows:** run HaloSetup.exe. Halo isn't code-signed yet, so if SmartScreen says "Windows protected your PC", click **More info › Run anyway**. Halo installs for your account (no admin rights needed) and appears next to the clock.

Then press **⌃⇧⌘H** (Mac) or **Ctrl+Shift+Alt+H** (Windows), or map a mouse button to it.

## What's in it

**macOS**
- Press ⌃⇧⌘H (or a mouse button you map to it) and pick an action: tap then click, or hold, point and release.
- Two looks: Classic (Logitech-style bubbles) and Glass (macOS Liquid Glass).
- Apps, websites, files, keyboard shortcuts, media and volume, screenshots, window layouts, Apple Shortcuts, scripts, text snippets, AI prompts, nested rings and multi-step Smart Actions.
- In-app actions for 30 apps such as Teams, Zoom, Slack, Figma and Outlook (Mute, Camera, Raise Hand…), menu commands, and buttons clicked for you where an app has no shortcut (Teams: Start Recording).
- Rings for specific apps, nested folders that open on hover, a one-click "Add to Ring" picker, full undo.
- Updates install themselves from inside Halo.

**Windows**
- Halo for Windows with the same ring, actions and per-app rings; installs with HaloSetup.exe and updates itself.
